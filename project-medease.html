MedEase

MedEase เป็นระบบสุขภาพอัจฉริยะผ่าน LINE Platform ที่พัฒนาเพื่อให้ผู้ใช้เข้าถึงข้อมูลสุขภาพ ข่าวสุขภาพ การนัดหมายแพทย์ และบริการผู้ช่วยแชทบอทได้สะดวกขึ้น โดยออกแบบให้เชื่อมโยงระหว่าง Web Application, LINE Messaging API และ Firebase

Role & Responsibility

  • ออกแบบและพัฒนา Web Application สำหรับผู้ใช้และผู้ดูแลระบบ
  • พัฒนา Back-end ด้วย Node.js / Express เพื่อรองรับ Webhook และ API
  • เชื่อมต่อ LINE Messaging API และ LINE LIFF สำหรับการใช้งานผ่าน LINE
  • จัดการข้อมูลด้วย Firebase / Firestore เช่น ข่าวสุขภาพ การนัดหมาย และคำร้องต่าง ๆ
  • ออกแบบแนวทางการใช้ AI Chatbot สำหรับตอบคำถามและช่วยนำทางผู้ใช้

Technology Stack
